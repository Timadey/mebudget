# mebudget

Simple, classic spend/budget tracker for Android.

---

## Overview
mebudget is a lightweight Kotlin Android app to help you track spending and manage simple budgets. It's designed to be easy to use with a minimal, classic interface — perfect if you want straightforward expense tracking without the complexity.

---

## Features
- Add and categorize expenses
- Create and track simple budgets
- View recent transactions and balances
- Lightweight and offline-first

## Quick Start

### Install APK
1. Open the landing page above on your Android device.
2. Download the latest APK.
3. If prompted, enable installation from unknown sources and install the APK.

### Build from source
1. Clone the repo:

   git clone https://github.com/Timadey/mebudget.git

2. Open the project in Android Studio.
3. Build and run on an emulator or device (Android SDK + Kotlin support required).
